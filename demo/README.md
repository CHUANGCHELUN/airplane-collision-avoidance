# Demo 說明

這三個腳本模擬飛機在機場地面滑行的場景，用來測試碰撞偵測系統的正確性。
執行前需要有 HBase 在運作，並設定好 `.env`。

## 腳本說明

| 檔案 | 說明 | 飛機數 |
|------|------|--------|
| `demo_haneda_v1.py` | 重現 2023/06/10 羽田機場碰撞事件（簡化版） | 10 |
| `demo_haneda_v2.py` | 重現 2023/06/10 羽田機場碰撞事件（完整版） | 19 |
| `demo_taoyuan.py`   | 桃園國際機場實測場景 | 13 |

羽田事件涉及航班：**TG-683**（泰國航空）與 **BR-189**（長榮航空）在 L 滑行道發生擦撞。
系統可在碰撞前約 **40～50 秒**發出警告。

## 執行方式

```bash
# 先確認 HBase 已啟動，再執行主程式
python core/main.py &

# 另開終端執行 demo（會把模擬資料寫入 HBase）
python demo/demo_haneda_v2.py
```
